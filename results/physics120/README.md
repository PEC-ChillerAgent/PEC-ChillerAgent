# 四模型120题汇总

`four_model_metrics.csv` 为论文选定四模型的汇总，`metrics_provenance.json`记录来源哈希和比较范围。它们由2026-11-23已审核结果提取，没有重新推理、改写回答或挑选多次生成中的最佳答案。

| 指标 | 分母与定义 |
|---|---|
| content_and_tasks_pass | 120份回答中，物理内容正确且完成问题全部要求；不确定不计通过 |
| strict_json_pass | 120份原始回答满足单answer字段、无重复键等JSON格式要求；不判断物理内容 |
| confirmed_critical_error_answers | 120份回答中含已确认关键公式、水侧、单位或真实缺项等错误的回答数；不含单纯漏答 |
| required_citation_supported_pass | 仅16道明确要求数值引用的题目，必需引用齐全且支持对应陈述 |

四模型内容通过数依次86、94、117、120。学生最后三份分别为两份漏答、一份待裁决；关键错误计数0不表示每题都完整，也不表示零风险。

比较集为8个共享基础工况×15类任务，是原128题结果已知后形成的后验子集。审核为身份可见的非专家助手初审。GPT名称为中转服务自报，上游身份未独立验证；本地与API的推理预算不同。正文不得把项目专用格式通过率当作其他模型的物理准确率，也不得将同一来源的120题视作120台独立机组。

研究还曾采集DeepSeek、Kimi和另外两个中转配置。这里遵照作者选择展示四模型，不声称研究只测试了四个模型。原始样本、完整回答和逐题审阅记录保留在研究归档，未随汇总代码包发布。
