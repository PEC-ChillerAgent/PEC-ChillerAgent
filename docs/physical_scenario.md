# 当前结果解读与实际机组分析

当前仿真统一使用 Buildings ElectricEIR；水侧物理计算可独立使用，无需训练。

## 区分测量、计算和模拟

- 实测制冷量：冷冻水质量流量 × 比热 × 进出水温差。
- 实测 COP：上述制冷量除以正实测功率；缺少流量或功率时留空。
- 模型制冷量、功率和 COP：由选定 ElectricEIR 性能记录、入口工况和设定温度计算。
- 实测出水温度与功率只参与比较，不驱动仿真状态。

选定性能曲线必须适用于目标机组。默认示例记录不是所有机组的健康基线；超出曲线温区会提示外推。

## 动态状态与时间

两侧动态热容由额定质量流量 × 时间常数 × 比热得到。默认时间常数各 30 秒；每个 run_id 独立初始化，默认冷冻出水 5°C、冷却出水 25°C，可显式修改。

输入按零阶保持，首点为初态；组内时间须完整并严格递增。不同设备、独立稳态试验或不连续实验不能直接拼为同一动态运行段。稳态模式独立求解各行，不使用初态和热容。

瞬态过程的水侧热量与模型热源之间存在储热差：

```text
蒸发侧储热速率 = 冷冻水侧换热量 − 模型制冷量
冷凝侧储热速率 = 模型冷凝热 − 冷却水侧换热量
```

该差值反映温度变化，不能直接当作稳态能量失衡或结垢证据。

## 提示与缺测

模拟冷冻出水低于 0°C 或冷却出水高于 60°C 会触发参考检查；它不是厂家运行边界，也不会自动停机。检查温标、流量单位、列映射、初态、设定值、性能曲线及时间段划分。

“涉及 N 个输出点”指结果行数，不是故障种类；单条恒定工况可生成多个仿真点。“—”表示无法计算该项，不表示零。

## 实际机组需要准备的信息

| 类别 | 内容 |
|---|---|
| 设备 | 机组编号、型号、额定冷量/COP/流量、性能曲线及适用范围 |
| 数据质量 | 源文件、工作表、来源行、传感器单位、采样间隔及有效标记 |
| 水侧边界 | 两侧进水温度和流量 |
| 控制和状态 | 出水设定温度、明确的 0/1 启停输入 |
| 验证测量 | 独立的功率、两侧出水温度及必要故障证据 |
| 动态设置 | 连续运行段、时间戳、初态与适配的时间常数 |

支持 US gpm；不能把 gpm 数值直接解释为 m³/h。数据列名带 `_K` 或 `_kg_s` 是内部标识，源数值的解释以 schema 中声明的单位为准。

## 校准与诊断边界

`/model/electric-eir/calibrate` 使用有依据的健康稳态数据拟合单个功率尺度。它不同时识别容量曲线、流量和动态热容；训练误差需要与独立验证结果分开。

异常提示先定位测量问题、模型适配与工况偏离，再提出候选原因。当前模型不包含制冷剂充注量或污垢热阻等完整故障机制。冷站/中央空调分析还需泵、塔、末端、负荷和设备拓扑。

数值对照及适用范围见 [Buildings 对齐说明](buildings_alignment.md)，Agent 的任务划分见 [工具化方案](agent_tool_architecture_2026-10-29.md)。
