# 教师轨迹采集与候选导出

智能分析对话会将采集记录保存在现有 SQLite 数据库的 `chat_audit_events` 表中。更新代码后重新启动服务即可用于后续对话，无需重新配置模型密钥。物理计算工作台本身不调用语言模型，也不会产生教师对话轨迹。

## 采集内容

- 会话绑定、已使用的历史轮次、数据集元信息、系统提示与关键代码哈希。
- 每次模型请求的消息、工具定义和生成参数快照；每次响应的可见消息、返回模型名、请求标识、用量和终止原因。
- 真实工具请求/返回、耗时、回答校验结果、自动重写和最终兜底状态。

配置中的 API 密钥、具名凭据字段和供应商私有思考字段不进入候选导出。为了满足兼容服务的协议要求，原有内部会话仍可保留供应商要求回传的思考字段；该字段不会进入导出。服务商未返回的用量、版本或终止原因保留为 null，不猜测补齐。供应商返回的模型名只是返回值，不构成独立身份认证。

采集按调用逐步写入，因此中途失败不会清掉已经保存的请求/结果。应用崩溃或磁盘写入失败可能造成不完整轨迹，导出会标记缺失。每次请求会保存消息快照，长期批量采集时需要关注数据库增长。

## 离线导出

在项目根目录执行，替换实际的轮次编号。轮次编号可从分析报告文件名 `turn_....md` 获得。

```powershell
python -m energy_agent.distillation.export --db outputs/energy_agent/agent.sqlite3 --turn turn_实际编号 --source-group 实际来源组 --output outputs/student_candidates/sample_review.json
```

该命令以只读方式打开数据库，不调用任何模型，不修改历史记录，也不允许覆盖已经存在的导出文件。

`source-group` 必须根据原始数据来源填写，同一试验的工作表、切片、缺测变体、改写问题属于同组。例如从同一个 RP-1043 normal 试验派生的 A/B/C 及后续变体均用 `rp1043_normal_entire_trial`。这不是自动分组算法；操作者仍需核对来源登记。未绑定数据的通用开发题可以单独登记开发组。

## 输出的含义

导出内容含目标轮次、需要的历史上下文、绑定的原始记录、引用的真实运行结果和逐次采集事件。

| 字段 | 含义 |
|---|---|
| `capture_status=application_trace` | 已保存本轮各次应用调用和最终事件；私有思考仍按设计省略 |
| `capture_status=legacy_or_partial` | 历史数据或未完成采集，不能假称拥有完整原始请求 |
| `outcome.repair_rounds` | 自动重写次数 |
| `outcome.fallback_used` | 是否触发确定性兜底，包括工具事实报告和失败提示 |
| `outcome.history_evidence_reused` | 本轮未新运行工具，引用了历史运行事实 |
| `training_approved=false` | 尚未完成人工审核；不直接用于训练 |
| `split=unassigned` | 尚未按来源组划分正式集合 |

历史对话不会补出当时没有记录的参数、用量或完整系统提示。遗留消息中的用户文本和数据仍属于原始材料，公开发布前需另行审查；导出不进行任意自然语言内容的全面脱敏。

这是一套候选采集与审计接口，不是完整 SFT 构建器。后续还需要内容审核、去重、按来源组划分、明确编辑版本、生成训练格式及检查 token/loss mask。不能把失败初稿、固定兜底报告和修正稿全部作为正确答案监督，也不能将同一会话的重复提问当作独立测试样本。

## 校验规则的边界

此次修正允许少量明确的中文动作/组织用语，不放行任意中文数字。标准句“缺测不代表测得零值”仅在已引用某个指标的零有效点数时可用。具体指标的零/非零断言仍要求对应事实支持；行数、COP、功率等业务数量仍须引用事实占位符。

运行相关回归测试：

```powershell
python -B -m pytest energy_agent/tests -q -p no:cacheprovider
```

测试使用本地协议模拟与真实物理工具，不调用付费教师。协议模拟通过不代表真实教师在新提示下已经通过业务评测。
