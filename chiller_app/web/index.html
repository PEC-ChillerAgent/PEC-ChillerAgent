02

计算方式

仿真模型：Buildings 13.0.0 · ElectricEIR（水冷制冷模式）

ElectricEIR 必需：两侧进水温度、两侧正流量、出水设定温度。实测功率、出水温度可留空。

上传的设定温度、启停列优先于上面的固定值。启停状态列必须是 0/1；ASHRAE 的 Unit Status 是多值代码，不会自动当作 0/1。模型功率仅含压缩机；性能曲线属于所选机组，新机组需校准。Buildings 水介质常数参考：cp=4184 J/(kg·K)，ρ=995.586 kg/m³。

查看 / 自定义机组参数

可修改额定冷量、COP、负荷范围及三组曲线系数。额定蒸发侧热流 QEva_flow_nominal 必须为负数；该编辑器中的参数不受输入单位切换影响。

ElectricEIR 每组独立初始化；留空使用冷冻出水 5°C、冷却出水 25°C，不读取实测出水作为初态。稳态模式忽略初态。

介质参数与计算原理

默认使用 Buildings.Media.Water 对应恒物性。更换物性后，对比时必须在两端一致设置。

实测计算：Qe = ṁe · cp · (Te,in − Te,out)
Qc = ṁc · cp · (Tc,out − Tc,in)；COP = Qe / P
ElectricEIR：P = −QEva,ava / COPnom · EIRFunT · EIRFunPLR · CR
QCon = −QEva + ηmotor · P
C = ṁnom · τ · cp；C · dT/dt = 水侧焓流 + 热源

ElectricEIR 动态使用 BDF 数值积分，稳态求解能量方程；性能曲线使用冷冻出水与冷却进水摄氏温度。仅对齐 ElectricEIR 水冷制冷模式，不含完整制冷剂循环、水力网络和其他 Buildings 模型。

无需训练模型，即可计算。
